# Code of Conduct

We want this project to be useful, respectful, and safe for everyone.

Participants must:

- communicate clearly and respectfully;
- focus criticism on code, behavior, documentation, and evidence;
- disclose relevant device, SDK, permission, and license constraints;
- avoid sharing credentials, personal data, signing material, or private vendor
  artifacts.

Harassment, discrimination, threats, doxxing, spam, and deliberate disclosure
of secrets are not accepted. Maintainers may remove content or restrict
participation when these expectations are not met.

Report conduct concerns privately to the maintainers listed in the GitHub
repository. Do not open a public issue for sensitive reports.
