# v0.1.0

Initial public release of `uni-baidu-map-harmony`, an open-source HarmonyOS NEXT native Baidu Maps adapter for traditional uni-app `APP-HARMONY` projects.

## Highlights

- Registers a native `<embed tag="baidu-map" />` through `defineNativeEmbed`.
- Integrates Baidu Maps HarmonyOS NEXT SDK through a UTS / ArkTS adapter layer.
- Adds lazy, process-wide SDK initialization with concurrent initialization protection.
- Requires explicit host-app privacy consent before SDK initialization.
- Keeps OAID collection opt-in and disabled by default.
- Supports controlled BD09 map center and initial zoom.
- Emits debounced `centerchange` events after map gestures.
- Supports one optional marker with a native `PopView` for name, distance, and address.
- Includes bilingual documentation, source validation, contribution guidelines, security policy, and third-party licensing notices.

## Scope

This release focuses on map rendering and map-local interaction. Device location, coordinate conversion, geocoding, POI search, route planning, navigation, and host-app privacy UI remain outside the adapter's scope.

## Important integration note

The Baidu vendor HAR is intentionally not redistributed in this repository. Obtain the compatible SDK through an authorized source and place it at:

```text
utssdk/app-harmony/libs/navi_map-2.0.5.har
```

Then run:

```bash
node scripts/verify-sdk.mjs --require-sdk
```

A valid Baidu Maps HarmonyOS AK, matching package/signature configuration, and required Harmony permissions are also required for real-device rendering.

## Verification

The repository can validate its source layout without the vendor binary:

```bash
node scripts/verify-sdk.mjs
```

Real HarmonyOS build and device verification must be performed from a compatible uni-app host project with the vendor SDK and a valid AK.
