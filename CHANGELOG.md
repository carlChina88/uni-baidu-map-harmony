# Changelog

All notable changes to this project will be documented in this file.

## [0.1.0] - 2026-08-24

### Added

- Initial public adapter extracted from a working uni-app HarmonyOS
  integration.
- Native `baidu-map` embed registration.
- Lazy Baidu SDK initialization with explicit privacy-consent input.
- BD09 center synchronization and debounced center-change events.
- Optional marker and PopView support.
- English documentation, contribution policy, security policy, licensing, and
  source validation script.

### Deliberately omitted

- The vendor Baidu HAR binary.
- Host-app assets, APIs, pages, stores, and location permissions.
