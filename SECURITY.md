# Security policy

## Supported versions

Security fixes are handled on the latest release branch. Older versions may
not receive fixes for vendor SDK, HarmonyOS, or uni-app compatibility issues.

> English is the default language. Expand the Chinese section at the end for
> the Chinese security policy.

## Reporting a vulnerability

Do not publish credentials, AKs, signing files, crash dumps containing user
data, or a suspected vulnerability in a public issue.

Use GitHub's private vulnerability reporting if it is enabled for the
repository. Otherwise, contact the repository maintainers privately and
include:

- the affected version;
- the HarmonyOS, HBuilderX, uni-app, and vendor SDK versions;
- reproduction steps and expected behavior;
- logs with secrets and personal data removed.

The project is an adapter around a third-party SDK. Vendor SDK vulnerabilities
should also be reported through Baidu's official security or support channel.

## 支持版本

安全修复会在最新发布分支处理。旧版本可能不会继续接收 Vendor SDK、HarmonyOS
或 uni-app 兼容性问题的修复。

## 漏洞报告

不要在公开 Issue 中发布凭据、AK、签名文件、包含用户数据的崩溃日志或疑似漏洞
细节。

如果仓库已启用 GitHub 私密漏洞报告，请使用该功能；否则请私下联系维护者，并
提供：

- 受影响的版本；
- HarmonyOS、HBuilderX、uni-app 和 Vendor SDK 版本；
- 复现步骤和预期行为；
- 已移除秘密和个人数据的日志。

本项目是第三方 SDK 的适配器。Vendor SDK 漏洞也应通过百度官方安全或支持渠道
报告。
